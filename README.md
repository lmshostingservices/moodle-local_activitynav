# local_activitynav

## Summary

Adds compact previous/next navigation arrows to the top-right of all activities.

## Description

Adds compact previous/next navigation arrows to the top-right of all activities. Works with subsections, Tiles, and phased courses. The 'Next' arrow only appears when completion is met.

## Current Release

Version 1.5.4 republishes the reviewed authoritative source under a new immutable tag because the historical tag contained a different source tree. There are no functional changes in this release.
